# 词间 · 单词学习

独立网页版，包含《晓艳带你学英语·六级高频单词》（1,768 个去重词条，10 个 Unit）、考研词汇（4,801）和雅思词汇（3,000 个单词 + 800 个词组）。六级按用户提供的词书原有 Unit、顺序和词义整理，原书 1,769 条中的 complement 重复一次，保留两个单元的归属。扫描识别释义仍可能有误，支持个人校对；考研基于 ECDICT 考试标签整理，不宣称为官方全量大纲。

支持中文选英文、英文回忆中文、可选逐字拼写、错词本、掌握度排行、跨词库去重、全库学习、浏览器读音和中英双向查词。

## GitHub Pages 部署

网页根目录为 `docs/`，入口为 `docs/index.html`，无需安装依赖或构建。

1. 打开仓库 Settings → Pages。
2. Build and deployment → Source 选择 Deploy from a branch。
3. Branch 选择 `main`，目录选择 `/docs`，保存。
4. 等待 Pages 构建成功，以设置页实际显示的访问地址为准。默认项目地址应为 https://tsa314ku-oss.github.io/cijian-vocab/ 。

后续更新 `main` 分支中的 `docs/` 会触发重新部署。不要把 GitHub 仓库地址当作网站地址。

## 个人数据与隐私

每个浏览器从空白进度开始。个人答题、复习日期、错词、校对与设置只保存在该浏览器的 localStorage（键名 `cijian-web-v1`）；不发送至服务器，不会自动同步设备。可在“数据与设置”中导出或恢复个人 JSON 备份。同一浏览器中的使用者共用一份存档，换设备或清理浏览器前请导出备份。

本仓库不包含任何桌面版个人进度、备份、原始 PDF、扫描页、服务端数据文件或访问令牌，也不修改已有桌面软件。查词词典不计入学习任务总数。

## 词典与验证

ECDICT 词典许可及来源见 `docs/licenses/`；按原许可保留作者署名。整理的词义可能有误，请结合语境核对。

使用 Node.js 运行 `node verify.cjs` 可验证词库分组、跨书共享记录、浏览器保存与隔离、备份格式及资源引用。
